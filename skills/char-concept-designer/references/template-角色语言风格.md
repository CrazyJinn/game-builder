# 角色语言风格模板

> 基于叙事设计中的"声音支柱"(Voice Pillar)模型，定义角色的语言行为规范。语言风格是剧本拆解时角色对话的参考基准。
> 生成后，各字段写入 LanguageStyle 图节点。映射关系见"各字段规则"中的标注；Schema 定义见 `00_init/Schema/角色美术.md`。

**适用范围**：仅主角和 NPC。怪物不生成语言风格。

---

## 编写要点

### 身份规则

角色文档包含身份分析（故事角色、核心创伤、欲望、需要），用于推导声音支柱。这些字段不写入图节点，但决定了以下内容的方向：

1. **核心创伤决定回避话题**：角色的创伤直接影响他们不愿意谈论的内容
2. **欲望与需要的矛盾决定潜台词**：角色说出口的和内心真实想法之间的差距

### 阵营词汇倾向

- 骑士团：军事术语、机械名词、务实表达
- 金属合唱团：粗犷口语、帮派黑话、张扬表达
- 教会：仪式化语言、宗教用语、权威语气
- 秘术协会：学术性词汇、含蓄表达、隐喻
- 平民：朴实口语、生活化表达

### 各字段规则

**词汇**：正式/随意、技术性/口语化、阵营术语偏好 → `LanguageStyle.vocabulary`

**句子节奏**：短促急迫 / 长句思考型 / 混合 → `LanguageStyle.rhythm`

**语言习惯**：口头禅、犹豫模式、特定短语 → `LanguageStyle.habits`

**情绪模式**：覆盖 5 种情境（平静/紧张/愤怒/悲伤/轻松），每种包含表达方式变化（具体描述语言行为变化，如"句子长度从平均8字缩短到4字"）和台词示例 → `LanguageStyle.emotion_patterns`

**他们绝不会说的话**：3 条，每条是完整台词 + 不符合的原因。覆盖三个维度：词汇/语气不符、价值观不符、情绪表达方式不符。仅供设计参考，不写入图节点

**标准台词**：3 条可直接用于剧本的台词——日常表达、有潜台词的对话、高压情境爆发。仅供设计参考，不写入图节点

**概要**：将身份概要 + 绝不会说的话 + 标准台词压缩为 1-2 句总结 → `LanguageStyle.description`

**流程状态**：→ `status` 设为 1（`id`、`name` 在创建节点时由流程步骤 3 设置）
