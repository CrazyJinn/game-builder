# 角色美术设定模板

> 根据角色需求文档、世界设定和人物设定，提取并结构化角色的视觉设计方向。美术设定是后续美术提示词生成的输入。
> 生成后，各字段写入对应的图节点。映射关系见"各字段规则"中的标注；Schema 定义见 `00_init/Schema/角色美术.md`。

---

## 编写要点

### 自描述规则

每份美术设定必须是**完全独立、自包含**的文档，满足以下要求：

1. 任何阅读者无需查阅其他角色文档即可完整理解该角色的视觉设计
2. 禁止使用跨角色对比式描述（如"与XX相同"、"比XX更..."、"XX所没有的"）
3. 外观相同的角色（如双胞胎）应各自独立描述外貌细节，通过各自的气质、材质状态、动态细节来区分，而非通过"与另一个人的差异"来定义
4. 如需标注关联关系，仅在"身份概要"或"特殊标记"中用一句话说明（如"与对应角色为双胞胎，容貌相同"），正文描述一律用绝对表述

### 各字段规则

**角色核心关键词**：视觉设计方向词（非纯性格描述），主角/NPC 3-5个、怪物 2-3个，覆盖不同维度（气质、战斗风格、时代感、阵营归属）。仅供设计方向参考，不写入图节点

**形状语言**：每个角色只选一个主导形状（三角型→敏捷 / 方型→厚重 / 倒三角→力量 / 细长型→速度 / 圆形→亲和 / 不对称→危险），理由说明形状如何体现在轮廓上 → `AppearanceStyle.shape_language`

**视觉气质定义**：一句话，不超过30字，同时包含外在视觉特征和内在气质暗示 → `AppearanceStyle.visual_tone`

**外貌特征**：包含体型、面部气质（怪物改为变异特征）、发型、特殊标记（疤痕/纹身，无则省略）。把握大体方向即可，具体细节留给提示词阶段。"面部气质"写整体感觉而非逐项列举五官 → `AppearanceStyle.appearance`

**面孔/人种**：描述角色的面孔类型/人种归属（如中国面孔、日系面孔、欧美面孔、混血面孔等），用于明确面部骨骼轮廓与气质倾向 → `AppearanceStyle.ethnicity`

**色彩方向**：一段话覆盖主色、辅色、点缀色及配色逻辑，不必拆成表格 → `Character.color_direction`

**玩家第一印象**：一句话描述玩家初次看到角色时的直观感受。禁止包含衣着描写（衣着由 CostumeStyle 节点负责） → `AppearanceStyle.first_impression`
