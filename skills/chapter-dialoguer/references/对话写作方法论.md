# 对话写作方法论

> 本 skill 用三轮打磨创作细节对话。本文件是对话质量标准与声音支柱方法论——第二轮·声音、第三轮·精简、声音回检都依据它。

## 对话写作标准（硬规则）

- **每句台词必须通过"真人会这样说话吗？"测试**——不允许把说明文伪装成对话。
- 角色有一致的声音支柱（词汇、节奏、回避的话题）——在所有对话里强制执行。
- **避免"你也知道"式对话**——角色之间不为让玩家了解情况而互相解释已知事实。
- 每个对话节点必须有明确的**戏剧功能**：揭示、建立关系、制造压力或传递后果。无功能的台词删掉。

## 角色声音支柱（声音回检依据）

每个角色应有声音支柱。本 skill 从 LanguageStyle 节点的字段（`vocabulary`/`rhythm`/`habits`/`emotion_patterns`/`description`）读出声音支柱，创作后回检一致性：

- **词汇**：正式 / 随意、技术性 / 口语化、地域特色。
- **句子节奏**：短促急迫 还是 长句思考型。
- **回避的话题**：这个角色从不直接谈论什么。
- **语言习惯**：特定短语、犹豫或模式。
- **默认潜台词**：这个角色是直说还是总在绕弯子？

**回检**：产出 lines 后，逐角色对照其声音支柱——台词是否用了他的词汇偏好 / 句式节奏 / 口头禅？不符合则改。

> 进阶锚点（本轮未接入）：角色的"绝不会说的话"（3 句听起来不对的台词示例）+ 标准台词范本。目前 LanguageStyle 不存这些，待声音支柱断流修复后可查用。

## 三轮打磨

### 第一轮·功能
每段 lines 完成明确叙事职责（揭示 / 建立关系 / 制造压力 / 传递后果），对齐 outline 拓扑 + 设计简报情感弧。这段在情感弧上哪个位置？推进什么情绪？无戏剧功能的台词在此轮删掉。

### 第二轮·声音
每句台词符合角色声音支柱，通过"真人会这样说话吗"测试。重点避免：
- **"你也知道"式对话**（角色互解释已知事实）。
- **on-the-nose 说明文伪装成对话**（角色直白说出动机/情绪）——改用潜台词、行为、反应传达。

### 第三轮·精简
删每个不值得存在的词。旁白不啰嗦、台词不留水分。精简后每条 `say`/`narrate` 都有其存在的必要。

## 潜台词（show, don't tell）

角色的欲望与需要的矛盾决定潜台词——他们说的不等于他们想的：

- 让角色说一套做一套（嘴上说不在乎，动作暴露在乎）。
- 用行为 / 反应传递情绪，而非角色自述情绪。
- 留白：不把每件事说透，让玩家推断。
