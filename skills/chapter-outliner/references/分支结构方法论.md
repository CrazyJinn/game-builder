# 分支与结构方法论

> 本 skill 产出提纲（scenes 骨架 + 分支拓扑）。本文件指导分支与戏剧结构怎么设计——节点图先行、选项本质差异、后果可见、节奏。方法论摘自叙事设计理论。

## 分支节点图先行（写一句台词前先画拓扑）

写任何提纲内容前，先用节点图厘清本章分支结构：

- 节点 = scene（场景段）；边 = `choice`/`jump` 的跳向。
- 标注：哪个 scene 分叉、分支在哪汇合、`ending` 落在哪。

自检（必须全过才落 outline.md）：
- **无死胡同**：每条分支最终汇合回主线或导向 ending，不存在走不通的路径。
- **自然汇合**：分支不是多条永不相交的平行线。死胡同或不可调和的路径需要显式设计理由（如 BE/TE 分流）。
- **落点存在**：`choice` 的每个 `option` 跳向的 scene id 都在本章 scenes 内。

> 节点图在脑内/草稿推演即可，不必落盘。目的是避免把对话写进结构性死胡同。

## 分支本质差异门控（有意义选择测试）

每个 `choice` 的 options 之间必须是**戏剧本质不同**，不是程度差异或 flavor：

- **本质差异**：不同价值观取向 / 不同后果路径 / 不同信息揭示。例：「再想想」vs「跳下去」（求生意志 vs 放弃）是本质差异。
- **非本质（flavor 级）**：「我来帮」vs「我晚点帮」（程度差异）、纯文案不同的同一后果。flavor 级选择不带来有意义决策。

命中 flavor 级差异 → **标注问题**，建议用户手动补 Choice 的戏剧分化。本次先按现状产出但标记待补。

## 后果可见（选择要有回响）

选项的后果必须在 **2 个场景内**产生可观察的回响——否则选择感觉毫无意义：

- **即时后果**：选完马上看到（角色反应、关系变化、新 scene）。
- **延迟后果**：前面做的选择在后面兑现。
- **后果可见度**：有的明显即时，有的微妙长期——有意设计这个比例，不要所有后果都同等显眼。

## 节奏与戏剧结构（scene 序的情绪曲线）

scene 序不是平铺，要有节奏——对齐上游设计简报的**情感弧线**：

- 标注 **turning point**（转折点：剧情/情感方向反转的 scene）。
- 标注 **climax**（高潮：情感张力最高的 scene）。
- 让情绪有起伏：铺垫 → 递进 → 转折 → 高潮 → 收束，而非从头到尾一个情绪。

> 提纲阶段只定"哪段是转折/高潮"的位置，具体台词由 dialoguer 填，但位置要立住。
