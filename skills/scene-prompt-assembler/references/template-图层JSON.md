# 场景图层 JSON 模板（SceneLayer / decor & mask）🚧 V2

> decor（陈设层）与 mask（遮罩层）的提示词以 **JSON** 形式产出（仅色调/位置描述，供图集式生成）。
> **V2 实现**：当前项目（对话游戏）仅需 background 层，本模板供 functional/combat 场景的 decor/mask 层未来使用。
> 迁移自原 `场景设计/references/战斗场景图层.md`。

## 房间类型（combat 场景）

| 房间类型 | 装饰密度 | 遮罩特征 | 氛围 |

## 装饰层（9宫格 / 4宫格）

装饰物按大小分两档，各自独立 JSON 文件：

| 类型 | 宫格 | 文件命名 | 适用 |
|------|------|---------|------|
| 小装饰 | 3×3 = 9格 | `装饰层_1.json` | 碎石、弹壳、枯枝等 |
| 大装饰 | 2×2 = 4格 | `装饰层_2.json` | 废弃车辆、岩石堆、大树桩等 |

**仅描述色调**，不描述形状、材质、大小。装饰多时可追加（`装饰层_3.json`...）。

```json
{
  "layer": "装饰层（Decoration）",
  "scene": "[场景名称]",
  "room": "[房间名称]",
  "requirement": "无任何文字,每个元素独立完整,格子之间用1px细线隔开,元素居中占格子80%",
  "style": {
    "background": "纯白背景,格子之间用1px细线隔开",
    "camera": "俯视角",
    "rendering": "[风格词：读 00_init/美术风格.md「提示词硬约束」风格收尾串，取其中风格描述部分]"
  },
  "order": ["1", "2", "3", "4", "5", "6", "7", "8", "9"],
  "elements": {
    "count": 9,
    "items": [
      { "label": "1", "description": "[仅色调描述]" },
      { "label": "2", "description": "[仅色调描述]" },
      { "label": "3", "description": "[仅色调描述]" },
      { "label": "4", "description": "[仅色调描述]" },
      { "label": "5", "description": "[仅色调描述]" },
      { "label": "6", "description": "[仅色调描述]" },
      { "label": "7", "description": "[仅色调描述]" },
      { "label": "8", "description": "[仅色调描述]" },
      { "label": "9", "description": "[仅色调描述]" }
    ]
  }
}
```

> 大装饰（4宫格）将 `order`/`elements.count`/`items` 改为 4 项，`layer` 改为「装饰层-大（Decoration-Large）」。

## 遮罩层（独立图片）

每个遮罩是独立的 JSON 文件，一个房间可有多个遮罩：`遮罩层_1.json`、`遮罩层_2.json`...

```json
{
  "layer": "前景/遮罩层（Foreground/Mask）",
  "scene": "[场景名称]",
  "room": "[房间名称]",
  "mask_id": 1,
  "requirement": "无任何文字,元素独立完整",
  "style": {
    "background": "纯白背景",
    "camera": "俯视角",
    "rendering": "[风格词：读 00_init/美术风格.md「提示词硬约束」风格收尾串，取其中风格描述部分]"
  },
  "elements": {
    "count": 1,
    "items": [
      { "label": "1", "description": "[遮罩的色调与位置描述]" }
    ]
  }
}
```

## 编写要点

- **概览先行**：combat 场景应先在 `概览.md` 中逐项列出每个装饰物/遮罩的内容与尺寸（装饰占格百分比、遮罩像素尺寸如 1920×400），JSON 严格按概览生成，不在 JSON 中重复尺寸
- **装饰层 description 仅色调**：如「黄褐色调的碎石」，不写形状/材质/大小
- **装饰分档**：小装饰 9 宫格，大装饰 4 宫格，数量不限可追加
- **遮罩独立**：每个遮罩单独一个 JSON，渲染在角色之上形成前景遮挡
- **密度按房间类型**：见房间类型表
