# 着装适配提示词模板（IllusDesign）

> IllusDesign 通过**图生图**方式生成，以 DesignSheet（设计图）为参考底图，角色外貌已在底图中。
> 提示词**聚焦着装描述，不重复角色外貌**。

---

## 输出模板

```markdown

## 着装提示词

1. **开头声明**：角色立绘设计图，[从美术风格.md 读取背景色]背景，全身三视图（正面、侧面、背面）
2. **着装款式** ← garment 标签（颜色+类型）：[层次（内搭/外层）+ 剪裁（收腰/宽松）+ 开衩/下摆等款式细节]
3. **材质质感** ← garment 标签（材质维度）：[从 garment 材质词展开面料质感，结合自定义标签补充的质感氛围、缝线/刺绣细节]
4. **配色** ← garment 标签（颜色维度）：[着装配色：主色用在何处，辅色用在何处，点缀色用在何处]
5. **鞋袜** ← footwear 标签：[款式 + 颜色]
6. **配饰** ← accessory_type 标签（含自定义具体样式）：[饰品位置 + 样式，手持物]
7. **适配补充** ← IllusDesign.adaptation_notes：[着装补充，如无则跳过]
```

---

## 编写要点

### 核心原则

1. **只描述着装**：不重复角色外貌（体型、面部、发型、发色、瞳色等），这些已在 DesignSheet 底图中
2. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词
   - 推荐：`身穿深蓝色收腰长外套，衣摆及膝，前襟敞开露出白色内衬，袖口收紧用银色纽扣固定`
   - 避免：`深蓝外套, 收腰, 及膝, 敞开, 银扣`
3. **着装配色写具体**：不要只写"黑白"，写成"外套主体为深蓝色，内衬为白色，领口和袖口以银色滚边点缀"

### 提取原则

1. **只提取不创作**：所有着装细节从 CostumeStyle 节点字段和 `00_init/美术风格.md` 提取，不添加数据中未提及的元素
2. **不遗漏**：对照输出模板逐项检查，确保每个维度都有覆盖
3. **细节转自然语言**：着装设定中的列举式描述转为连贯的自然语言句子
