# 角色设计图提示词模板（DesignSheet）

> DesignSheet 通过**文生图**方式生成，聚焦角色外貌，不涉及衣着设计。
> 角色统一穿着深色基础衣物（如黑色贴身背心+深色短裤），与肤色形成高对比，衣着由后续 IllusDesign 专门处理。

---

## 输出模板

```markdown
# 设计图提示词

## 画风
<!-- 数据来源：00_init/美术风格.md -->

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面）
2. **背景**：[角色图片背景色]
3. **线条**：[线条粗细 / 统一性 / 风格化 / 纹理 / 色彩]
4. **上色与光影**：[上色类型 / 阴影硬度 / 光影立体感]
5. **比例**：[头身比例 / 身体比例]
6. **色调**：[主色调 / 饱和度 / 对比度]

## 角色设定
<!-- 数据来源：AppearanceStyle 节点（appearance, ethnicity）+ Character 节点（color_direction） -->

1. **体型** ← AppearanceStyle.appearance：[身高 / 体型曲线 / 肩线 / 静态站姿]
2. **面部** ← AppearanceStyle.appearance + AppearanceStyle.ethnicity：[面孔人种 / 脸型 / 眼型+眼色 / 眉型 / 鼻 / 唇 / 默认表情气质]
3. **发型** ← AppearanceStyle.appearance：[发色 / 长度 / 发型 / 质感 / 碎发细节]
4. **贴身基础衣物**：穿着深色基础衣物（如黑色贴身背心+深色短裤），与肤色形成高对比，不涉及服装设计细节
5. **外貌配色** ← Character.color_direction：[发色、瞳色、肤色等外貌相关配色]
6. **特殊标记** ← AppearanceStyle.appearance：[疤痕 / 纹身 / 胎记 / 身体异征]
```

---

## 编写要点

### 提示词核心规则

1. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词
   - 推荐：`身形修长，肩线略窄，四肢纤细，腰线清晰`
   - 避免：`修长, 窄肩, 纤细, 收腰`
2. **主体 + 细节 + 风格**：先写清楚主体，再补充细节和风格
3. **明确用途**：开头声明"角色设计图"让模型理解生成目标
4. **配色写成描述**：不要只写"黑色长发"，写成"及腰的黑色直发，发尾微微卷曲，在光线下泛着深蓝色光泽"
5. **风格词放末尾**：美术风格和参考作品放在提示词最后

### 三视图专用规则

1. **三视图格式**：单张图片包含正面、侧面、背面三个视角并排展示
2. **一份提示词**：每个角色仅一份提示词
3. **背景色**：从美术风格.md 读取角色图片背景色，提示词中包含"[背景色]背景"
4. **全身像**：每个视角完整展示角色全身设计
5. **三视角一致**：同一角色三个视角保持外观一致
6. **不使用负面提示词**：Seedream 通过正面描述控制画面
7. **静态姿态**：设计图仅展示静态站姿，双手自然垂于身侧或微微张开，禁止出现交叠、叉腰、持物等动态手部动作。角色的体态气质差异通过肩线、重心、含胸/挺胸等躯干状态体现，手部动作留给立绘和精灵帧表现

### 提取原则

1. **只提取不创作**：所有视觉细节从图节点字段（AppearanceStyle）和 `00_init/美术风格.md` 提取，不添加数据中未提及的元素
2. **不遗漏**：对照输出模板逐项检查，确保每个维度都有覆盖
3. **细节转自然语言**：美术设定中的列举式描述转为连贯的自然语言句子
