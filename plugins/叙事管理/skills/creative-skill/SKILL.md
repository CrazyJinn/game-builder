# 创作 Skill

基于图数据进行推理和创作，输出剧情建议并自动发现新实体回流到图数据库。

## 模式

### 探索模式

用户不指定方向，由 Skill 主动探索图数据，发现有趣的隐藏关系、叙事缺口、角色发展机会。

### 输入模式

用户提供具体的创作需求（如"写一段角色A和角色B的互动"），Skill 基于需求查询相关图数据后生成。

## Workflow

### 1. 图谱检索

根据用户需求（探索模式则全图扫描），使用neo4j-helper查询 Neo4j：
- 角色及其关系网络
- 事件因果链和时间线
- 信息节点的知识层级分布
- 场景及其关联的角色和事件

### 2. 时间线推理

沿事件因果链推理：
- 识别时间线上的缺口和跳跃
- 推断未描述但逻辑上必然发生的事件
- 分析事件之间的因果合理性

### 3. 角色关系推理

基于角色关系网络推理：
- 分析角色之间的潜在冲突和联盟
- 推断角色的动机和行为模式
- 发现关系网络中的关键节点（信息中介、权力中心等）

### 4. 世界观一致性检查

检查生成内容与已有世界观设定的一致性：
- 角色行为是否符合已设定性格
- 事件发展是否符合已建立因果链
- 新信息是否与已有知识层矛盾
- 场景描写是否符合已设定环境叙事属性

### 5. 生成创作输出

根据推理结果生成：

| 输出类型 | 说明 |
|---------|------|
| 剧情建议 | 基于事件链和角色关系的下一步发展建议 |
| 角色互动 | 两个或多个角色之间的对话/行为场景 |
| 支线事件 | 独立于主线的小事件，丰富世界观 |
| 场景扩展 | 对已有场景的环境叙事补充 |

### 6. 自增长：发现新实体和关系

在创作过程中自动发现：

| 发现类型 | 说明 | 回流方式 |
|---------|------|---------|
| 新实体 | 创作中提到但图中不存在的新角色/地点/势力 | 通过 neo4j-helper 写入新节点 |
| 隐藏关系 | 已有实体间未被记录的关系 | 通过 neo4j-helper 写入新边 |
| 补充设定 | 对已有实体的属性补充（如新发现的性格特征） | 通过 neo4j-helper 更新节点属性 |


## 约束

- 生成内容必须通过世界观一致性检查，不通过则重新生成
- 新发现的实体/关系标注为"推理生成"，与原始素材区分
- 不修改用户明确确认的已有设定，除非用户要求
