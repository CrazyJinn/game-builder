# 美术提示词生成

根据角色美术设定，生成通用的 AI 绘图提示词，输出**设计图提示词**和**立绘提示词**。

## 编写原则

提示词为通用格式，不针对特定图片生成模型。核心规则：自然语言优先，按 主体→细节→风格 组织，不使用负面提示词。详细规则见 [template-设计图提示词.md](references/template-设计图提示词.md)。

## 执行流程

### 1. 解析用户输入

从用户的自然语言输入中提取以下信息：

1. **目标角色**：识别角色名称或编号（如"陆择"、"char_001"）。
   - 若输入的是角色**编号**（如 `char_001`），直接使用
   - 若输入的是角色**名称**（如"陆择"），读取 `01_叙事数据/角色实体.md` 查表获取对应编号
   - 若用户未指定具体角色（如"为所有角色生成提示词"），读取 `01_叙事数据/角色实体.md` 获取全部角色列表
   - 若用户指定"所有角色"之外的范围（如"女主们"、"星耀电竞的角色"），根据角色实体的 description 和上下文筛选匹配角色
2. **产出类型**：识别用户要求生成的内容类型：
   - `设计图提示词` — 三视图设计图提示词
   - `立绘提示词` — 立绘变体提示词
   - 未指定时默认两者都生成
3. **额外约束**：用户可能提出的特定要求（如"只生成P0角色"、"风格偏写实"等），作为生成约束融入结果。

**角色编号查表**：`01_叙事数据/角色实体.md` 格式为：

```
| 编号 | 姓名 | 性别 | description | 上下文 |
```

按姓名匹配编号，同时获取 description 和上下文作为补充信息。

**示例输入**：
- "为 char_001 生成设计图提示词" → 角色: char_001, 产出: 设计图提示词
- "给陆择生成全部美术提示词" → 查表→ char_001, 产出: 设计图+立绘提示词
- "为所有角色生成提示词" → 全部角色, 产出: 设计图+立绘提示词
- "生成女主们的立绘提示词" → 查表筛选→ char_002/char_004/char_006/char_007/char_008, 产出: 立绘提示词

### 2. 提取信息

1. 读取 `05_角色设计/char/<角色ID>/美术设定.md`（核心输入，路径中的 char/npc/enemy 从编号前缀推断）。文件缺失则终止并报告
2. 读取 `05_角色设计/char/<角色ID>/语言风格.md`（立绘表情变体的情绪参考）。文件缺失时仅影响立绘变体数量，不终止
3. 补充来源（可选，文件不存在时跳过）：
   - `00_init/世界设定.md` → 阵营设计参考

### 3. 判断产出

根据角色类型和需求决定提示词类型：

| 角色类型 | 设计图提示词 | 立绘提示词 |
|---------|:----------:|:--------:|
| 主角 | 按需 | 按需 |
| NPC | 按需 | 按需 |
| 怪物 | 不生成 | 不生成 |

### 4. 生成提示词

输出目录为 `06_角色美术/<角色ID>/`，完整结构见 [overview-structure.md](references/overview-structure.md)。

**命名规则**：按角色ID直接建文件夹，不按阵营区分。

**全局风格**：`角色美术总览.md` 定义全局风格（如"轻写实日系二次元，纯白背景"），角色级提示词继承，不重复声明。

按模板生成：
- `设计图提示词.md` — 按 [template-设计图提示词.md](references/template-设计图提示词.md)
- `立绘/提示词.md` — 按 [template-立绘提示词.md](references/template-立绘提示词.md)

信息来源：角色外貌/配色/体态从 `05_角色设计/<类型>/<角色ID>/美术设定.md` 提取，不重复创作。已有角色文件夹时仅更新内容。

### 5. 更新总览

更新 `06_角色美术/角色美术总览.md`（结构见 [references/overview-structure.md](references/overview-structure.md)）

### 6. 更新 Neo4j status 与路径

将已处理角色的 status 更新为 `2`（美术提示词完成），同时写入提示词文件的相对路径。

**通过 neo4j-helper skill 以自然语言执行更新**：

> "更新编号为 <角色编号> 的角色节点，设置 status 为 2，design_prompt_path 为 '06_角色美术/<角色编号>/设计图提示词.md'，stand_painting_prompt_path 为 '06_角色美术/<角色编号>/立绘/提示词.md'"

批量更新时逐个执行。前置检查：若角色 status < 1（角色设计未完成），跳过并记录到 unable_to_process。

## 提示词语言

所有提示词使用**中文**自然语言描述。
