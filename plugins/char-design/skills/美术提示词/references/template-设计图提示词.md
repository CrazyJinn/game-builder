# 角色设计图提示词模板

---

## 提取映射

从 `美术设定.md` 提取细节，按以下维度组织，确保每个维度的细节完整无遗漏：

| 美术设定字段 | 提取维度 | 细节粒度示例 |
|------------|---------|------------|
| 外貌特征 → 体型 | body | 身高、体型曲线、肩线、站姿 |
| 外貌特征 → 面部 | face | 脸型、眼型/眼色、眉型、鼻、唇色/唇形、默认表情 |
| 外貌特征 → 发型 | hair | 发色、长度、发型、质感、配件 |
| 外貌特征 → 特殊标记 | accessories | 饰品、手持物、疤痕、纹身 |
| 材质方向 | clothing 材质 | 面料质感（丝绸/皮革/金属等）、缝线/刺绣细节 |
| 色彩方向 | clothing 配色 | 主色→用途、辅色→用途、点缀色→用途 |
| — | clothing 款式 | 层次（内搭/外层）、剪裁（收腰/宽松）、开衩/下摆 |
| — | footwear | 鞋袜款式、颜色 |
| 体态气质 | posture | 默认站姿（仅静态，双手自然垂于身侧） |
| — | dynamics | 飘动物品、风的效果 |

## 输出模板

```markdown
# [角色名称] 设计图提示词

## 角色信息
- **角色ID**：[ID]
- **阵营**：[阵营]
- **优先级**：[P0/P1/P2]

## 三视图提示词

[按以下顺序，用自然语言写一段完整的画面描述：]

1. **开头声明**：角色设计图，纯白背景，全身三视图（正面、侧面、背面）
2. **体型**：[身高/体型/曲线/肩线]
3. **面部**：[脸型/眼型+眼色/眉型/鼻/唇/默认表情气质]
4. **发型**：[发色/长度/发型/质感/碎发细节]
5. **服装**：[款式层次+剪裁+面料+细节装饰+开衩/下摆]
6. **配色**：[主色用在何处，辅色用在何处，点缀色用在何处]
7. **鞋袜**：[款式+颜色]
8. **饰品/手持物**：[饰品位置+样式，手持物]
9. **风格标签**（放末尾）

## 玩家记忆点（设计重点）
- [从美术设定"玩家记忆点"提取，确保这些元素在提示词中被强调]
```

## 编写要点

### 提示词核心规则

1. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词
   - 推荐：`身穿轻型外骨骼装甲，机械感护肩覆盖双肩，胸甲贴合躯干`
   - 避免：`外骨骼, 机械护肩, 胸甲, 装甲`
2. **主体 + 细节 + 风格**：先写清楚主体，再补充细节和风格
3. **明确用途**：开头声明"角色设计图"让模型理解生成目标
4. **配色写成描述**：不要只写"黑白灰"，写成"装甲主体为黑色与深灰色搭配，关节处露出白色内衬"
5. **风格词放末尾**：美术风格和参考作品放在提示词最后

### 三视图专用规则

1. **三视图格式**：单张图片包含正面、侧面、背面三个视角并排展示
2. **一份提示词**：每个角色仅一份提示词
3. **纯白背景**：提示词中包含"纯白背景"
4. **全身像**：每个视角完整展示角色全身设计
5. **三视角一致**：同一角色三个视角保持外观一致
6. **不使用负面提示词**：Seedream 通过正面描述控制画面
7. **静态姿态**：设计图仅展示静态站姿，双手自然垂于身侧或微微张开，禁止出现交叠、叉腰、持物等动态手部动作。角色的体态气质差异通过肩线、重心、含胸/挺胸等躯干状态体现，手部动作留给立绘和精灵帧表现

### 提取原则

1. **只提取不创作**：所有视觉细节从 `美术设定.md` 提取，不添加设定中未提及的元素
2. **不遗漏**：对照提取映射表逐项检查，确保每个维度都有覆盖
3. **细节转自然语言**：美术设定中的列举式描述转为连贯的自然语言句子
