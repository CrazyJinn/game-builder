# 角色美术设定模板

> 根据角色需求文档、世界设定和人物设定，提取并结构化角色的视觉设计方向。美术设定是后续美术提示词生成的输入。
> 生成后，各字段需写入对应的图节点（AppearanceStyle / CostumeStyle），见下方"字段→图节点映射"。

---

## 完整版（主角、NPC）

```markdown
# [角色名称] 美术设定

## 身份概要
- **角色ID**：[char_xxx / npc_xxx / enemy_xxx]
- **阵营**：[阵营名称]
- **优先级**：[P0/P1/P2]

## 角色核心关键词
[3-5个设计方向关键词，如"戒备、少年感、废土生存者、外骨骼轻装"]

## 形状语言
- **选择**：[三角型 / 方型 / 倒三角 / 细长型 / 圆形 / 不对称]
  - 三角型 → 敏捷、灵动
  - 方型 → 厚重、稳固
  - 倒三角 → 力量、压迫
  - 细长型 → 速度、精锐
  - 不对称 → 危险、不稳定
- **理由**：[如"三角型——偏瘦少年体型，动作敏捷，整体轮廓上宽下窄"]

## 视觉气质定义
[一句话定义角色的视觉气质，如"废土中认真生活的少年士兵，戒备中透着逞强"]

## 外貌特征
- **体型**：[如"178cm，偏瘦但结实，少年体型"]
- **面部气质**：[一句话描述面部给人的感觉，如"深褐色细长眼透着警觉，瓜子脸轮廓分明"]
- **发型**：[如"深灰黑色短发，略微凌乱，硬质发"]
- **特殊标记**：[疤痕/纹身/变异/配饰印记，无则省略]

## 材质方向
[主要材质和质感，如"磨砂金属外骨骼 + 帆布织物 + 磨损皮革，整体哑光质感，做旧磨损痕迹明显"]

## 色彩方向
[主色、辅色、点缀色及其与阵营/性格的关联，如"主色深灰（骑士团黑白灰体系），辅色卡其（废土实用主义），点缀深红（护甲细节），整体冷色调中透一丝暖色"]

## 体态气质
- **站姿**：[如"警惕，重心微前倾"]
- **动作风格**：[如"干脆利落，步伐稳健"]

## 玩家第一印象
[如"看起来很警觉，但又像个倔强的孩子"]

## 玩家记忆点
- [如：斜挎帆布工具包]
- [如：深褐色细长眼]
- [如：卡其色工装外套卷到小臂]
```

## 编写要点

### 数据来源优先级

1. inputs 中的角色外貌描述（若已提供）
2. `00_init/世界设定.md` → 阵营配色体系、世界观背景（inputs 无外貌细节时据此创作）
3. `01_需求文档/角色需求.md` → 角色性格、动画需求
4. `00_init/人物设定.md` → 角色核心信息、性格补充

### 自描述规则

每份美术设定必须是**完全独立、自包含**的文档，满足以下要求：

1. 任何阅读者无需查阅其他角色文档即可完整理解该角色的视觉设计
2. 禁止使用跨角色对比式描述（如"与XX相同"、"比XX更..."、"XX所没有的"）
3. 外观相同的角色（如双胞胎）应各自独立描述外貌细节，通过各自的气质、材质状态、动态细节来区分，而非通过"与另一个人的差异"来定义
4. 如需标注关联关系，仅在"身份概要"或"特殊标记"中用一句话说明（如"与char_007为双胞胎，容貌相同"），正文描述一律用绝对表述

### 各字段规则

**角色核心关键词**：视觉设计方向词（非纯性格描述），3-5个，覆盖不同维度（气质、战斗风格、时代感、阵营归属）

**形状语言**：每个角色只选一个主导形状，理由说明形状如何体现在轮廓上

**视觉气质定义**：一句话，不超过30字，同时包含外在视觉特征和内在气质暗示

**外貌特征**：把握大体方向即可，具体细节留给提示词阶段。"面部气质"写整体感觉而非逐项列举五官

**材质方向**：2-4种主要材质，含质感描述（哑光/光泽、粗糙/光滑），与阵营风格一致

**色彩方向**：一段话覆盖主色、辅色、点缀色及配色逻辑，不必拆成表格

**体态气质**：站姿描述必须是可以用于设计图三视图的**静态站姿**（肩线、重心、含胸/挺胸、躯干状态），禁止包含持物、叉腰、交叠等手部动作。手部动作和标志性道具留给立绘和精灵帧表现。

**玩家记忆点**：2-3个具体视觉元素，在低分辨率下仍可辨识，优先角色独有元素

### 反例：体态气质中的持物描述

体态气质中混入手部动作和持物描述，会导致下游设计图提示词违规（设计图仅允许静态站姿，禁止持物）。

**错误写法**：
```
## 体态气质
- **站姿**：笔直优雅，双臂自然交叠或单手持咖啡杯，气场强大
```

**正确写法**：
```
## 体态气质
- **站姿**：笔直优雅，重心居中，肩线平直，气场强大
- **动作风格**：动作精准克制，常单手持咖啡杯（立绘/CG表现）
```

标志性道具（咖啡杯、水壶、手账本等）放在**特殊标记**或**动作风格**中并标注"(立绘/CG表现)"，不写入站姿描述。

## 字段→图节点映射

美术设定生成后，各字段写入以下图节点：

### AppearanceStyle 节点

| 美术设定字段 | 图节点属性 |
|------------|----------|
| 外貌特征（整体） | appearance |
| 色彩方向 | color_direction |
| 形状语言 | shape_language |
| 视觉气质定义 | visual_tone |
| 玩家第一印象 | first_impression |
| 玩家记忆点 | memory_points |

### CostumeStyle 节点

| 美术设定字段 | 图节点属性 |
|------------|----------|
| 外貌特征→着装描述 | default_outfit |
| 材质方向 | material_direction |
| 体态气质 | posture |
| 特殊标记→配饰 | accessories |
