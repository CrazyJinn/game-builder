# 角色语言风格模板

> 基于叙事设计中的"声音支柱"(Voice Pillar)模型，定义角色的语言行为规范。语言风格是剧本拆解时角色对话的参考基准。

**适用范围**：仅主角和 NPC。怪物不生成语言风格。

---

## 模板

```markdown
# [角色名称] 语言风格

## 角色

### 身份
- **故事角色**：[主角 / 反派 / 导师 / 盟友 / 旁观者 / 等]
- **核心创伤**：[什么经历塑造了这个角色的世界观，如"战后失去家人，对升格者有深层不信任"]
- **欲望**：[他们有意识地想要什么，如"找到足够的物资活下去"]
- **需要**：[他们真正需要什么，通常与欲望矛盾，如"学会信任他人"]

### 声音支柱
- **词汇**：[正式/随意，技术性/口语化，阵营术语偏好，如"随意口语化，偏好军事术语和机械名词"]
- **句子节奏**：[短促急迫 | 长句思考型 | 混合，如"短句为主，紧张时更短促"]
- **他们回避的话题**：[这个角色从不直接谈论什么，如"从不谈论自己的过去和战前记忆"]
- **语言习惯**：[特定短语、犹豫模式、口头禅，如"习惯用'嗯'开头表示思考，紧张时省略主语"]
- **默认潜台词**：[直说还是绕弯子？如"表面上直来直去，但涉及情感时用行动代替言语"]

### 他们绝不会说的话
1. "[不符合角色的台词]"——[为什么不对]
2. "[不符合角色的台词]"——[为什么不对]
3. "[不符合角色的台词]"——[为什么不对]

### 标准台词（已批准的声音范本）
- "[台词 1]"——展示词汇和节奏
- "[台词 2]"——展示潜台词运用
- "[台词 3]"——展示压力下的情绪表达

### 情绪模式
| 情境 | 表达方式变化 | 台词示例 |
|------|------------|---------|
| 平静 | [与默认声音支柱一致] | |
| 紧张/压力 | [如：句子更短、术语更密集] | |
| 愤怒 | [如：声音变冷、省略敬称] | |
| 悲伤 | [如：沉默增多、避免眼神] | |
| 轻松/高兴 | [如：罕见的长句、轻微自嘲] | |
```

## 编写要点

### 数据来源优先级

1. `00_init/人物设定.md` → 角色性格特点、背景故事、核心动机
2. `01_需求文档/角色需求.md` → 性格描述、阵营信息
3. `00_init/世界设定.md` → 阵营语言风格基调（科技阵营偏务实简洁，魔法阵营偏神秘/仪式感）
4. `00_init/剧本大纲.md` → 角色在剧情中的行为表现

### 声音支柱规则

1. **核心创伤决定回避话题**：角色的创伤直接影响他们不愿意谈论的内容
2. **欲望与需要的矛盾决定潜台词**：角色说出口的和内心真实想法之间的差距
3. **阵营影响词汇选择**：
   - 骑士团：军事术语、机械名词、务实表达
   - 金属合唱团：粗犷口语、帮派黑话、张扬表达
   - 教会：仪式化语言、宗教用语、权威语气
   - 秘术协会：学术性词汇、含蓄表达、隐喻
   - 平民：朴实口语、生活化表达

### "绝不会说的话"规则

1. 每条台词必须具体（不是抽象描述，而是完整的台词句子）
2. 解释应说明为什么不符合角色（而非仅仅说"这不像他"）
3. 三条台词应覆盖不同维度：
   - 第一条：**词汇/语气**不符（如粗人说文绉绉的话）
   - 第二条：**价值观**不符（如自私的人说利他的话）
   - 第三条：**情绪表达方式**不符（如内敛的人突然大呼小叫）

### 标准台词规则

1. 三条台词分别展示声音的不同层面：
   - 台词 1：日常状态下的典型表达方式
   - 台词 2：有潜台词的对话（表面意思与真实意图不同）
   - 台词 3：高压情境下的情绪爆发
2. 台词应可直接用于剧本，不需要修改

### 情绪模式规则

1. **变化描述**应具体：不只是"变得更激动"，而是描述语言行为的具体变化（如"句子长度从平均8字缩短到4字"）
2. **台词示例**应与变化描述一致
3. 五种情境覆盖游戏中最常见的对话场景
